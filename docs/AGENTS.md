# Агенты (типы отвечающих)

Агент — компонент, который по запросу пользователя и контексту (RAG, граф) формирует **текст ответа**. Выбор агента: по типу задачи (позже — по метке в очереди или по правилам в воркере). На старте один агент.

---

## 1. Универсальный помощник (первый агент)

**Назначение**: общий ответ на мысль/вопрос пользователя с учётом карты мыслей и RAG.

### Входы

- **query**: текст сообщения пользователя (после транскрипции, если был голос).
- **user_id**: владелец данных.
- **rag_context**: список релевантных чанков из RAG (топ-k по сходству с query). Каждый элемент: `text`, при желании `source_node_id`.
- **graph_context** (опционально): последние узлы пользователя или соседи затронутых узлов — кратко (например, заголовки/суммари) для понимания «где мы в карте».

### Поведение

- Промпт собирается из:
  - Роль: «Ты помощник по карте идей пользователя. Отвечай кратко и по делу.»
  - Контекст из RAG: «Релевантные мысли пользователя: …»
  - Контекст из графа (если есть): «Недавние темы: …»
  - Запрос пользователя: «Сообщение пользователя: …»
- ИИ возвращает один ответ (текст). Ограничение длины — по лимиту Telegram (4096) и по разумному объёму для чтения в чате (например, до 500–1000 символов без обрезки).

### Выход

- **reply_text**: строка для отправки пользователю в Telegram.

### Ошибки

- Таймаут/сбой API ИИ → вернуть сообщение об ошибке («Временная ошибка, попробуй позже») и логировать.
- Пустой ответ от ИИ → подставить заглушку («Мысль принята, контекст учтён») или повторить запрос один раз.

---

## 2. Будущие агенты (идеи)

- **Только суммаризатор**: не отвечает развёрнуто, а только обновляет суммаризацию ветки/узла и коротко подтверждает («Записал, обновил итог»).
- **Вопросы по карте**: режим «покажи карту» / «что у меня по теме X» — ответ структурированный (список тем, ссылки на узлы).
- **Напоминания**: отдельный поток/агент, который по расписанию или по правилам формирует напоминания из записанных мыслей и шлёт в Telegram.

Выбор агента в следующих итерациях можно делать по ключевым словам в запросе, по отдельной команде бота (/summarize, /map) или по полю в очереди (agent_type).
